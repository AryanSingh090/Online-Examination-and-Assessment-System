# Online-Examination-and-Assessment-System
Online Examination and Assessment System - Full Stack Project

## Project Structure

- index.html
- style.css
- js/login.js
- pages/login.html
- pages/student-dashboard.html
- pages/teacher-dashboard.html
- pages/exam.html
- pages/result.html

## Features

- Responsive landing page
- Login form
- Front-end email/password validation with student/teacher dashboard routing
- Student dashboard
- Teacher dashboard
- Exam page
- Result page

## How to run

Open `index.html` in a browser.

Choose Student or Teacher in the login form to open the matching dashboard.

The login flow is a front-end demo only. It does not authenticate credentials or
connect to a backend.
